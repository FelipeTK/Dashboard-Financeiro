# Dashboard Financeiro

PWA/SPA financeiro com identidade visual em tons de preto, cinza e azul.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Router
- vite-plugin-pwa

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estrutura inicial

- Menu lateral expansível (ícones quando retraído)
- Header com busca de menus (atalho `Ctrl/Cmd + K`)
- Rotas: Início (`/`) e Financeiro (`/financeiro`)
